# Application Screenshots Guide

Capture the following screenshots when running the Employee Management System for your Week 2 internship submission:

### 1. `01-dashboard-overview.png`
- **Description:** Full dashboard view showing the sidebar, top header, summary statistics cards (Total Employees and Departments count), search bar, and employee data table with realistic records.

### 2. `02-add-employee-modal.png`
- **Description:** The "Add New Employee" modal dialog open with empty inputs, highlighting the form fields: Full Name, Email, Department selector, and Designation.

### 3. `03-form-validation-errors.png`
- **Description:** The Add/Edit form displaying inline field validation messages when required fields are left blank or when an invalid email format is entered.

### 4. `04-edit-employee-modal.png`
- **Description:** The "Edit Employee Details" modal populated with an existing employee's data ready to be updated.

### 5. `05-delete-confirmation-dialog.png`
- **Description:** The deletion confirmation modal showing the employee's name, department, designation, and warning prompt before deleting the record.

### 6. `06-search-and-filtering.png`
- **Description:** The dashboard showing filtered search results after typing a query (e.g. employee name or department) into the real-time search bar.

### 7. `07-responsive-mobile-view.png`
- **Description:** Browser window resized to mobile width (or DevTools mobile mode ~375px) showing responsive collapse of the table and hamburger menu.
